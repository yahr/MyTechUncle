매일 보고서, 자동으로 받기 전에 정리할 5가지

개발자 없는 회사 대표님용 체크리스트

보고서 자동화는 프로그램보다 정리가 먼저예요. 아래 5가지를 종이 한 장에 적어 보시면 무엇을 자동으로 만들 수 있는지, 어디부터 손대면 되는지 바로 보여요.

  1. 매일 보는 숫자를 한 줄씩 적어요

    보고서에 들어가는 숫자만 적어요. 많을수록 좋은 게 아니라, 실제로 보고 판단하는 숫자만 남겨요.

    예: 어제 매출, 주문 수, 취소·반품 수, 광고비

  2. 숫자마다 어디서 오는지 옆에 적어요

    쇼핑몰 관리자 화면, 엑셀 파일, 광고 관리 화면, 은행 앱처럼 출처를 하나씩 붙여요. 자동화는 출처 단위로 만들어져요.

  3. 지금 어떻게 가져오는지 적어요

    다운로드 버튼으로 받는지, 화면을 보고 손으로 옮기는지, 누가 메일로 보내 주는지 적어요. 다운로드나 연동이 되는 출처부터 쉬워요.

  4. 언제, 누가, 어디서 보는지 정해요

    매일 몇 시까지 필요한지, 대표님만 보는지 팀이 같이 보는지, 메일·메신저·구글 시트 중 어디로 받을지 정해요.

  5. 지금 하루에 몇 분 쓰는지 재 봐요

    며칠만 시간을 재 보면 자동화할 가치가 있는지 판단이 서요. 매일 쓰는 시간이 길수록 먼저 할 일이에요.

사람이 하는 게 나은 경우도 있어요

  • 출처 화면이 자주 바뀌거나 매번 다른 파일로 오는 숫자
  • 숫자를 보고 사람이 판단해서 고쳐 적어야 하는 항목

이런 건 억지로 자동화하지 않고, 나머지를 먼저 자동으로 만든 다음 사람이 확인만 하게 나눠요.
